# ArtPraxis repository instructions

## Approved brand source of truth

For every task that creates, reviews, or modifies ArtPraxis UI, UX, styling, components, layouts, logos, icons, imagery, marketing surfaces, or generated visual prompts:

1. Read `docs/brand/ARTPRAXIS_BRAND_GUIDE.md` before making changes.
2. Inspect `docs/brand/artpraxis-brand-kit-final.png` when visual context is relevant.
3. Use `docs/brand/artpraxis-design-tokens.json` and `docs/brand/artpraxis-design-tokens.css` for approved brand values.
4. Treat these files as newer and authoritative when older repository assets or documentation conflict.
5. Preserve accessibility, responsive behavior, and existing product functionality while applying the brand system.
6. Do not reinterpret, replace, or materially change the approved brand system without explicit brand-owner approval.
7. Do not modify the source-of-truth files as a side effect of ordinary UI work.
