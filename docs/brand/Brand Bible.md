## Snapshot (until full Bible is written)

**Personality:** Elegant, artistic, timeless, human, craft, professional, refined, observational, intentional, patient, premium.

**Never:** Cute, cartoon, messy, rainbow, craft-store, children’s-app.

**Color anchors:** Deep Navy `#0D1B2A`, Warm Ivory `#F7F5F2`, Brush Brown `#8B5E3C`, Warm Gray `#8A8278`.

**Logo:** Serif wordmark + realistic brush + painted stroke; tip connects to stroke. Studio sidebar uses a dedicated stacked lockup (`variant="sidebar"`), not a scaled primary. Collapsed chrome uses the mark only. See Logo Standards.

**Generation wait:** Loading screens use a reference plate + vertical pipeline checklist (pending → active → complete) with a rotating Studio Tip. No brush GIF animations, fake percentages, or spinners. See [UI Patterns](../design/ui-patterns.md).

**Voice:** See [Writing Style Guide](../Writing%20Style%20Guide.md).
