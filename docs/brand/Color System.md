## Core palette (from approved package)

| Name | Hex | Use |
|------|-----|-----|
| Deep Navy | `#0D1B2A` | Wordmark, primary strokes, primary UI |
| Warm Ivory | `#F7F5F2` | Paper backgrounds |
| Brush Brown | `#8B5E3C` | Brush bristles / accents |
| Warm Gray | `#8A8278` | Secondary text |
| Soft Blue Gray | `#DBDEE6` | Subtle supports |

## Rules

- Logo lockups stay in the approved navy / brown / blue-paint system.  
- Artwork-adaptive accents may harmonize with paintings — **not** a license to recolor the logo.  
- Prefer CSS variables already in the app (`--brand-navy`, etc.) over one-off hex.
